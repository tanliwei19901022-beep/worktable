# 金融工作台（个人版）

一个单文件 HTML 金融看板，零外部依赖、数据存本地、可在手机/电脑浏览器直接打开。

## 包含模块
- **全球盘面**：汇率（直连实时）、大宗商品、主流股指、数字货币（直连实时）
- **实时要闻**：置顶敏感/重要要闻
- **亚太板块**：沪深 / 港股 / 日经 / 韩国，含板块表现、资金流向、代表个股、中国恐慌指数
- **欧美板块**：欧洲 / 美国，同结构
- **每日简报**：日线总结与机会风险（来自 `brief.json`）
- **K 线弹窗**：点品种名查看走势，支持滚轮缩放

## 部署（GitHub Pages）
1. 在 GitHub 新建一个空仓库（如 `finance-desk`）。
2. 本地执行：
   ```bash
   git remote add origin https://github.com/你的用户名/你的仓库名.git
   git branch -M main
   git push -u origin main
   ```
3. 仓库 → Settings → Pages → 选 `main` 分支、`/ (root)` 目录 → Save。
4. 等 1~2 分钟，访问 `https://你的用户名.github.io/你的仓库名/`。

## 数据更新说明
- **汇率 / 数字货币**：页面在浏览器端直接拉外网 API，部署后依然实时刷新。
- **每日简报（股指 / 大宗 / 亚太 / 欧美板块 / 恐慌指数）**：由 `brief.json` 提供。
  推送后该文件是静态的，如需持续更新，需让生成脚本每天把新的 `brief.json` 提交回仓库（GitHub Actions 或本地自动 push）。
